      DESIGN DECISIONS // THE "WHY"

      Architectural Rationale

      • No React / Fiber: Direct imperative WebGL avoids React reconciler overhead, eliminating GC stutter in 60 FPS animation loops.
      • Vanilla JS + Typed JSDoc: Deterministic render lifecycle and single source of state without hydration delays or bundle bloat.
      • Camera Capped < 850ms: Eliminates recruiter waiting friction while preserving 3D spatial continuity across the motherboard.
      • Genuine Runtime Telemetry Only: Zero synthetic benchmark figures; all metrics derive directly from renderer.info and hardware APIs.
      • Physical PCB-to-Domain Mapping: Every portfolio category anchors to an authentic physical component (CPU=Bio, GPU=Projects, Caps=Skills, USB=Experience).
      • Boot Sequence Cached: First visit plays a 2.8s hardware POST; return visits bypass instantly via localStorage.

      SUBSYSTEM 01 // GRAPHICS

      Graphics & Shaders

      • Engine: Three.js r185 WebGL 2.0 Renderer
      • Shaders: Custom procedural materials (woven FR-4 fiberglass bump mapping, ENIG 24K gold, specular copper traces)
      • Post-Processing: Selective UnrealBloomPass with dynamic quality-budget scaling (1024 / 768 / 512)
      • Camera Engine: Parametric CatmullRom 3D flight paths coordinated with GSAP 3.15 ScrollTrigger
      SUBSYSTEM 02 // ARCHITECTURE

      State Machine & Modules

      • State Machine: 8 formal states (OFF, BOOTING, IDLE, INSPECTING, ACTIVE, OVERCLOCK, SLEEP, SHUTDOWN)
      • 8 Project Modules: CrowdPulse (CP1), Dialora (DL1), Smart Parking (SP1), BusIT (BT1), AquaDot (AQD1), PawPal (PX1), EcoMentor (EM1), ML Reps (ML1)
      • Memory Management: Designed to avoid unnecessary allocations during the render loop using pre-allocated scratch registers
      • Tick Scheduler: Tiered priority scheduling (CRITICAL, STANDARD, DEFERRED)
